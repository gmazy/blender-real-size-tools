<h1 align="center">Real Size Tools for Blender</h1>
<p align="center"><i>Add-on to help view models and images in their actual real life size</i></p>


## How it works

### Viewport in Actual Size (Wip)
1. Click on `View` > `Viewpoint` > `View in Actual Size`
2. Expand box in bottom left corner of screen and set `Screen DPI` to value matching your screen.
3. Blender view dimensions should now match real life. Verify it using physical ruler on screen.

### Background Image in Actual Size
1. Drag and drop image file with correctly set metadata into Blender, for example image from flatbed scanner.
2. Blender will create empty with the image. Go to properties of empty and click on `View in Actual Size`

### Image Editor in Actual Size
1. Open image in image editor and and click on `View` > `Zoom` > `View in Actual Size`
2. If size is not correct, double check screen DPI in add-on preferences.
<br>

## 📥 Install
Download the master branch as a .zip file. 

In Blender go to `Edit` > `Preferences` > `Add-ons`. Drag and drop the .zip file into the window to install.
